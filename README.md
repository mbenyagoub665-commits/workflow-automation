# Workflow Automation

Build workflows of steps that call APIs, branch on conditions, wait for approval, send email, ask a model and keep rows in data tables. They run when you click Run, on a schedule or when their webhook is called.

Inspired by https://n8n.io

Built with [oss.new](https://oss.new) for [EveryApp](https://github.com/every-app/every-app).

## Features

- Create, rename, duplicate and delete workflows of connected steps, with branches that rejoin and expressions such as `{{ $json.field }}`.
- Start a workflow by hand, on a schedule in UTC, or from its own webhook URL.
- Use HTTP request, condition, set fields, wait, approval, send email, AI prompt and data table steps.
- Keep encrypted credentials that only you can use in HTTP request steps.
- See every run step by step, filter runs by status, cancel, retry from the failed step or replay.
- Browse each workflow's saved versions, see what changed and restore any of them.
- Keep typed data tables that you edit in a grid and use from workflows.
- Share workflows and tables with the team; owners and admins delete, unshare and transfer them.

Left out: accounts and sign-in, which your Gateway handles; code steps; the catalogue of ready-made app integrations; templates; AI agents and chat; insights dashboards; enterprise administration; billing.

## Setup

```sh
pnpm install
pnpm everyapp dev      # run locally
pnpm test              # unit tests
pnpm run deploy        # deploy behind your Gateway
```

Install a release with `pnpm everyapp install <repository url>`. The packaged-release checks in `checks/` run against a built release with the oss.new runtime.

- `CREDENTIALS_KEY` (secret, generated by the deploy): encrypts saved credentials.
- Optional: an OpenRouter key on the Gateway (`pnpm everyapp provider add openrouter`) turns on AI prompt steps.
- Optional: email on the Gateway turns on Send email steps.

## Limitations

- Schedules run on a one-minute cron, so a run can start up to a minute after its time.
- Wait steps resume on that cron, so short waits take up to a minute.
- HTTP request steps time out after at most 120 seconds.
- Runs are kept for 30 days.
- A data table grid shows the first 2,000 rows.
- Sending email and AI prompts were checked only in their "not set up" state; real delivery and model calls were not tested here.
